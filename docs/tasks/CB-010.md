# [CB-010] コード変更の差分プレビュー・選択適用・取り消しを追加する

<!-- codebot-task:CB-010 -->

- 優先度: P1（開発支援）
- 状態: 未着手
- 依存: CB-008、CB-009
- 根拠: 初期設計書4.2「コードの変更案と実際の変更を区別」「差分を提示」

回答に含まれる修正案を、実ファイルへ反映できるようにする。提案作成と書き込みを分け、実行前に利用者が変更内容を確認する。

完了条件:

- [ ] 追加・更新・削除を構造化した変更案として扱い、GUI/CLIにファイルごとの差分を提示する。
- [ ] 利用者が対象ファイル・変更箇所を選んで適用でき、承認前にファイルを書き換えない。
- [ ] 読み込み後にファイルが変わっていた場合は競合として停止する。作業ルート外の変更を拒否する。
- [ ] 適用内容を記録し、既存の未コミット変更を失わず直前の適用を取り消せる。複数ファイルの途中失敗を検証する。
