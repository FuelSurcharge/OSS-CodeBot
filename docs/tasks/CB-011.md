# [CB-011] 確認付きのコマンド実行とテスト結果表示を追加する

<!-- codebot-task:CB-011 -->

- 優先度: P1（作業自動化）
- 状態: 未着手
- 依存: CB-008
- 根拠: 初期設計書FR-010「承認を前提に開発作業を自動化」、6章の外部ツール層

ビルド・テストなどのコマンドを、実行内容と作業場所を確認したうえでアプリから実行し、結果を会話へ戻せるようにする。

完了条件:

- [ ] コマンド・引数・作業ディレクトリ・環境変数名を実行前に表示し、利用者が実行を選択できる。
- [ ] 出力を逐次表示し、終了コード・所要時間・タイムアウトを記録する。本文や秘密値を診断ログへ無条件に記録しない。
- [ ] キャンセル・アプリ終了時に、その操作が起動した子プロセスをOSごとに終了できる。
- [ ] コマンド文字列の意図しないシェル解釈を避ける。非ゼロ終了・大量出力・子プロセスを伴う実行を検証する。
