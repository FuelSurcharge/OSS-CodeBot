# [CB-013] アプリからGitHub Issue・Pull Requestを扱えるようにする

<!-- codebot-task:CB-013 -->

- 優先度: P1（GitHub連携）
- 状態: 未着手
- 依存: CB-012
- 根拠: 初期設計書FR-007とPhase 3「Issue・Pull Request連携」

これはCodeBotアプリ本体にGitHub連携を追加するタスク。開発管理用のIssue登録作業とは別に、利用者のリポジトリのIssue/PRを開発コンテキストとして扱う。

完了条件:

- [ ] 認証と対象リポジトリを選択し、Issue/PRの一覧・本文・差分を読み込める。
- [ ] Issueから作業ブランチを準備し、選択したIssue本文をチャットへ取り込める。
- [ ] Issue作成・PR作成・コメント投稿の本文と送信先をプレビューし、利用者の操作で投稿できる。
- [ ] 権限不足、レート制限、通信切断、重複投稿を扱う。トークンをログや通常の設定ファイルへ保存しない。
