全20件中、完了5件・残り15件（アプリ13件、将来構想2件）。CB-001・003・004・008・009は2026-11-09に実装・検証完了。

各ファイルには、現状・優先度・完了条件・依存関係を記載している。
更新時は個別ファイルとAI-ISSUES.mdを合わせて変更し、コミットしてpushする。
ファイル管理用IDはGitHub Issueの番号とは別のもので、GitHub上のIssue状態とは自動同期しない。

## GitHubへの登録用スクリプト

`scripts/create_github_issues.py`は、将来GitHub Issuesへ登録するときの補助ツールとして残す。
通常のタスク更新では実行不要。実行する場合は既存Issueとの重複を確認し、完了済みCB-003を未完了として登録しないよう内容を確認する。

現時点ではファイルを進捗管理の基準とし、GitHub Issueの作成・更新は行っていない。
