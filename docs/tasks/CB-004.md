# [CB-004] チャットの保存・再開・名前変更・削除・書き出しを追加する

<!-- codebot-task:CB-004 -->

- 優先度: P1（基本操作の拡張）
- 状態: 実装・検証完了（2026-11-09）
- 依存: CB-001
- 根拠: `readme.md`「会話履歴はアプリ起動中のみ保持」、`codebot-gui/src/main.rs`のSession

終了すると消える会話と下書きを、利用者が選択した場合にローカル保存して再開できるようにする。

完了条件:

- [x] 保存の有効・無効と保存先を設定でき、再起動後に会話・下書き・選択中のチャットを復元できる。
- [x] チャットの名前変更、検索、削除、Markdown/JSONへの書き出しを用意する。削除時に対象が分かる。
- [x] APIキー・HFトークンを会話メタデータへ保存しない。保存対象と外部送信範囲を区別して表示する。
- [x] 保存途中の終了、壊れたデータ、容量不足、旧バージョンの形式を扱い、元データを壊さずエラーを示す。

実装・検証:

任意保存・保存先指定・名前変更・検索・確認付き削除・Markdown/JSON書き出しを追加。同一フォルダの一時ファイルから保存を置換し、不正JSON・未知のバージョン・8 MiB超過・保存失敗を検出。元ファイルは自動上書きせず、再読み込み時の重複も防止する。復元時は履歴送信の同意を解除する。使い方は[チャット保存](../CONVERSATIONS.md)。

Linuxで操作検証。Windows/macOSの実機確認はCB-016で追跡する。GitHub Issue本体の状態は変更していない。
