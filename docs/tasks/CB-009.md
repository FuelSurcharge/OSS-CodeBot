APIへ自由文を送る基盤は実装済み。選択したコードやログに対して、説明・不具合調査・レビューを実行し、根拠となるファイルや行を確認できるようにする。

完了条件:

- [x] GUI/CLIから「説明」「エラー調査」「レビュー」を選び、対象ファイル・差分・ログを渡せる。
- [x] 指摘にファイル名・行番号・理由・修正案を付け、対象箇所へ移動できる。確認できない内容は推測と区別する。
- [x] ローカルAI/APIの双方で使え、処理前に送信する対象と利用モデルが分かる。
- [x] 既知の不具合を含む小さなサンプルで、入力範囲・根拠表示・失敗時の再試行操作を確認する。

実装・検証:

共通の説明・調査・レビュー指示、GUIの操作選択、CLIの--action、codebot-fileリンクによる作業フォルダ内の行表示、失敗後の再試行を追加。既知のゼロ除算候補を含む小さなコードを模擬APIで検証し、選択範囲と引用クリックを実GUIで確認。推論品質の検証ではない。使い方は[説明・レビュー](../WORKSPACES.md)。
