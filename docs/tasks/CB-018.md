# [CB-018] 権限を明示するプラグイン拡張の最小仕様を作る

<!-- codebot-task:CB-018 -->

- 優先度: P2（基本的な開発支援の後）
- 状態: 完了（2026-11-09。実装・自動検証・Linux実GUI/CLI検証済み）
- 依存: CB-010、CB-011、CB-015
- 根拠: 初期設計書FR-008、Phase 3「プラグイン機構」

コアを書き換えずに開発支援機能を追加できるよう、拡張の境界と必要権限を定義する。最初は1つのサンプル拡張を動かす範囲に絞る。

完了条件:

- [x] 読み込み方式、manifest、互換バージョン、入出力、失敗時の扱いを仕様書にする。
- [x] ファイル読み込み・書き込み・コマンド・通信など、要求する権限を導入前に表示する。
- [x] 書き込みと実行は既存の確認フローを通す。権限外の操作、クラッシュ、タイムアウトがアプリ全体へ波及しない構成を検証する。
- [x] サンプル拡張の導入・無効化・削除をGUI/CLIで確認し、拡張作者向けの最小ガイドを用意する。

実装と検証:

- [拡張仕様・導入手順・作者向けAPI v1](../PLUGINS.md)。WASI/importなしのWasm32をwasmiで処理。導入前にmanifest・権限・SHA-256を表示し、導入後は無効。入力・結果の専用保存やAIへの自動送信は行わない。
- 選択した参照データのみを渡し、書き込みとコマンドは共通ツール形式の提案に限定。既存の差分・コマンド確認を通し、権限外・直接通信は拒否。管理処理ではゲストコードを実行しない。
- ゲストのリニアメモリ64 MiB・実行量10,000,000 fuel・入出力サイズを制限。無限ループ/start関数、trap、メモリ超過、不正ポインター、未許可提案、WASI import、改変、確認後の削除内容変更、プロセス間ロックを検証し、失敗後の別拡張実行も確認。秒単位の厳密な実時間期限は提供しない。
- Rust製サンプルを同梱。CLIの導入プレビュー・確認拒否・導入・有効化・入力/選択ファイル処理・無効化・削除を別プロセスで確認。別の変更提案用拡張でも、既定では変更しないことと確認付き適用を実CLIで確認。
- Linux実GUIで権限表示・無効状態での導入・有効化・2行の日本語入力・無効化・再起動後の復元・削除を確認。変更提案は差分表示中には書き込まず、チェックと適用後に指定した1ファイルだけを作成し、変更記録と元のチャット下書きを保持。通常の変更画面から記録を参照して取り消しを実行し、元からあったファイルを保持することも確認。
- Rustテスト114件、Pythonテスト8件、workspaceビルド、整形・差分チェックが成功。通常サイズと700×540のLinux実画面を撮影。

Windows/macOS実画面はCB-016、ライセンス・配布はCB-017で継続。署名付き拡張、自動更新、マーケットプレイスは最小仕様の対象外。
