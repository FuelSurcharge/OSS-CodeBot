# [CB-018] 権限を明示するプラグイン拡張の最小仕様を作る

<!-- codebot-task:CB-018 -->

- 優先度: P2（基本的な開発支援の後）
- 状態: 未着手
- 依存: CB-010、CB-011、CB-015
- 根拠: 初期設計書FR-008、Phase 3「プラグイン機構」

コアを書き換えずに開発支援機能を追加できるよう、拡張の境界と必要権限を定義する。最初は1つのサンプル拡張を動かす範囲に絞る。

完了条件:

- [ ] 読み込み方式、manifest、互換バージョン、入出力、失敗時の扱いを仕様書にする。
- [ ] ファイル読み込み・書き込み・コマンド・通信など、要求する権限を導入前に表示する。
- [ ] 書き込みと実行は既存の確認フローを通す。権限外の操作、クラッシュ、タイムアウトがアプリ全体へ波及しない構成を検証する。
- [ ] サンプル拡張の導入・無効化・削除をGUI/CLIで確認し、拡張作者向けの最小ガイドを用意する。
