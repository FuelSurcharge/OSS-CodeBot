# OS別の操作・配布検証

以下は検証対象の案であり、動作保証済みの最低要件ではありません。依存ライブラリや実機検証で必要な条件が判明した場合は更新します。

| 対象 | CPU | ビルド用CI | 実画面・配布検証 |
|---|---|---|---|
| Windows 10 22H2 / Windows 11 | x86_64 | windows-2022 / MSVC | 未実施 |
| macOS 11以降 | Intel x86_64 / Apple Silicon arm64 | macos-15で両targetをビルド | 未実施。ビルド用OSと最低対象OSは別 |
| Ubuntu 22.04以降 | x86_64 / glibc | ubuntu-22.04 | クラウドLinuxのXvfb/X11で機能確認。Ubuntuの新規ユーザー環境・Waylandは未実施 |

macOSのInfo.plistは11.0を検証対象の下限として指定します。署名・公証と各CPUの起動は未検証です。Windows ARM、Linux ARM・musl、32bit、Intel/AMD以外の追加CPU最適化は配布対象に含めていません。

## 実施記録（2026-11-09）

LinuxクラウドのXvfb/X11で、LINE Seed JP/BIZ UDPゴシックの表示、通常サイズ・700×540、設定/チャット保存、下書き保持、模擬APIの日本語ストリーム・停止、選択ファイル・差分・取り消し、確認付きコマンドとGit、模擬GitHub API、拡張の導入/実行/無効化/削除を確認しました。ローカルCPUのtorch/Transformers診断と合成safetensorsも確認しています。実API認証・Hugging Face実通信・学習済みモデルの日本語推論・GPUは未検証です。

Xvfbの日本語入力は貼り付け/既存入力を使用しました。IME変換、OSのクリップボード連携、読み上げ、高DPI、Linux Waylandは未確認です。Windows/macOSのテスト実行結果・実画面も取得していません。CI定義の存在と、CIが実際に成功したことを区別します。
