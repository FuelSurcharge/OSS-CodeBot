# 確認付きコマンド実行とテスト結果

## GUI

ヘッダーの「実行 → コマンドを確認して実行」で、作業フォルダのフルパス・実行ファイル・引数を入力する。
引数は1欄につき1つ。スペースを含む値も1つの引数として渡す。引用符をコマンドライン用に追加する必要はない。
「環境変数と実行上限」で追加で引き継ぐ変数名、タイムアウト、出力量を指定できる。

「実行内容を確認」で、実際に解決した実行ファイル、引数の境界、作業場所、引き継ぐ環境変数名、実行上限を表示する。
この操作ではコマンドを起動しない。確認欄を選び、「確認したコマンドを実行」で開始する。
入力を変更すると前の確認を無効にする。AI処理中とファイル変更の処理中には実行できない。

標準出力・標準エラーを逐次表示し、終了コード・所要時間・停止・タイムアウト・出力上限を表示する。
画面では各ストリームの末尾20000文字を表示し、コピーは取得した全出力を対象とする。
結果は「チャットの下書きへ追加」で、既存の下書きを残して追加する。最大12000文字までで、省略がある場合は表示する。送信は別の操作。
実行後はその作業フォルダの古い参照ファイルと送信用履歴を無効にする。次の要求ではファイルを選び直す。

## CLI

`--workspace 作業フォルダ --run-command 実行ファイル`を使う。
`--command-arg`を引数ごとに繰り返す。フラグを渡す場合は`--command-arg=-I`のように`=`で指定できる。
`--pass-env`は追加で引き継ぐ環境変数名を指定する。
`--command-timeout`は秒、`--output-limit-kib`はKiBで指定する。

実行内容のプレビューを表示した後、`run`入力で実行する。EOF・異なる入力では中止する。
`--command-preview`は表示だけで終了する。`--yes`は確認の明示的な省略。
Ctrl+Cで実行を止める。出力は逐次フラッシュし、終了時は本文を含まない状態・終了コード・時間・出力量を表示する。
非ゼロ終了・中止・タイムアウト・出力超過はCLIの失敗終了になる。

## 実行環境と制約

- コマンドは現在のユーザー権限で動き、ファイル変更・外部通信が可能。標準入力は閉じ、対話端末は使用しない。
- 実行ファイルと引数配列を直接渡す。シェル展開は自動で行わず、.bat/.cmdの暗黙実行を拒否する。インタープリターを明示した場合は、そのインタープリターの指定内容を実行する。
- PATH・ホーム・一時フォルダ・言語・Rust環境・Windowsビルド環境等の基本変数と、利用者が明示した変数だけを渡す。APIキー等を含む環境全体を自動継承しない。指定した追加変数が未設定なら、実行前に通知する。
- プレビューには環境変数の名前だけを表示する。TOKEN・SECRET・KEY・PASS・認証等の名前を持つ既知の変数値は、出力の分割をまたいで伏せ字にする。ファイルやコマンド自身が出力する未知の秘密値を網羅できる機能ではない。
- 出力はGUI/CLIの利用者向け表示へ渡し、通常のアプリ診断ログや専用ログファイルへ本文を自動保存しない。チャットへの追加・コピーは明示的な操作。
- UTF-8の途中分割を保持する。不正な文字や端末制御文字は置き換える。既定の出力上限は標準出力・標準エラーの合計1 MiB、設定範囲は1 KiB〜4 MiB。超過時は停止する。
- タイムアウトの既定は120秒、設定範囲は1〜3600秒。確認後に実行ファイルの場所・サイズ・更新時刻、または作業場所が変わった場合は再確認を求める。
- Unixは操作専用のプロセスグループ、WindowsはJob Objectにまとめて停止する。通常終了した親が子を残した場合も終了させる。GUI終了時は出力受信を閉じて停止を通知し、実行スレッドを回収する。
- 自らUnixのプロセスグループを離脱するデーモンや、OSの強制終了・電源断・停止不能なカーネルI/Oについては終了を保証しない。サービス常駐用の操作には使用しない。

## 検証

Linuxで実プロセスを起動し、承認前の無変更、引数の非解釈、フィルターされた環境、日本語、非ゼロ終了、大量出力、タイムアウト、キャンセル、通常終了後の子孫終了、変更された実行ファイルの拒否をテストした。
GUIの実行スレッドが出力待ちになった状態から、アプリ終了処理で停止・回収できることもテストした。
実GUIで確認付き実行・逐次出力・終了状態、既存下書きへの追加、所有する子プロセスの停止を確認。GUIの表示用コマンドはテスト用スクリプトで、プロジェクト全体のテスト結果ではない。
Windows/macOSの実行結果は未取得。OS別の実装と共通テストを既存の3 OS CIへ含めたが、この変更のCI結果は未確認。実機GUI検証はCB-016で追跡する。
